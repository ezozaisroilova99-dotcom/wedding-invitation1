Свадебное приглашение Shaxzodbek & E’zozaxon

Файлы:
- index.html — страница
- style.css — дизайн
- script.js — анимации, таймер и музыка

Музыка:
Положите свой MP3-файл рядом с index.html и назовите его music.mp3.

RSVP:
Сейчас кнопки открывают WhatsApp без номера. Перед публикацией замените ссылки в index.html на номер WhatsApp получателя.

Бесплатная публикация:
Загрузите эти файлы в новый GitHub repository и включите Settings → Pages → Deploy from branch → main → /root.
